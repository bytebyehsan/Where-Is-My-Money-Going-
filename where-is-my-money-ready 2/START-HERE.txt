WHERE IS MY MONEY? - START HERE

1. Open this project in VS Code.
2. Go to backend and run:
   npm install
3. Copy backend/.env.example to backend/.env
4. Put your MongoDB Atlas connection string in MONGO_URI.
5. In backend:
   npm run dev
6. Open another terminal:
   cd frontend
   npm install
   npm run dev
7. Open the localhost URL shown by Vite.

Never share your MongoDB password or JWT secret.
